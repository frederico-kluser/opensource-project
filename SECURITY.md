# Security Policy

## Supported Versions

| Versão | Suportada |
|---|---|
| última release (SemVer) | ✅ |
| versões anteriores | ❌ |

## Reporting a Vulnerability

**Não abra issues públicas para vulnerabilidades.** Use o
[GitHub Private Vulnerability Reporting](https://docs.github.com/pt-br/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
ou contacte `security@ondokai.example`.

Resposta prometida em 48 h; divulgação coordenada após correção (embargo máximo de
90 dias, com advisory público e crédito ao reporter).

Este repositório é uma agent skill (instruções e ferramentas): os relatórios mais
relevantes são injeção de prompts nos templates/assets, comandos que exponham
credenciais e gates contornáveis nos scripts.
